# Where each figure comes from

A percentage answers "how much"; this answers "which". Each measurement carries the detail it was
computed from — documents per format, lint findings per rule — and this page lays it out worst
first, which is the order somebody fixing it would work in.

Only the worst few lines of each metric appear here, so that a committed file's diff stays readable.
The complete detail is one command away and is never truncated:

```sh
freeports-dev ci-report --format json | jq '.metrics[] | .breakdown'
```

How many lines a document shows is a setting, in the three tiers everything else here uses —
`--breakdown-limit N`, then `FREEPORTS_CI_BREAKDOWN_LIMIT`, then `report.breakdown_limit` in
`ci.yaml`, then fifteen. `0` means all of them.
