# What a commit here has to clear

Every minimum this repository declares, taken from `ci.yaml` at its root — the same table
`freeports-dev ci-check` applies, and the same one `freeports-dev ci-report --table thresholds`
prints.

**Cost** says when the figure is taken: a `fast` metric is measured at every commit, a `slow` one is
read at commit time from the last full run. **What it measures** is the sentence that keeps a
percentage from being read as a different percentage — `tests.formats.integration` counts documents
that have a whole-document test *at all*, not documents whose test passes.

A minimum here is a floor this repository has already cleared, never an aspiration. One seeded above
the measured figure refuses the first commit made under it, and then it is the gate somebody
switches off rather than the code somebody fixes.
